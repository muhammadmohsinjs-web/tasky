# Tasky Branding Master

## Use for
- New brand creation or rebrand decisions
- Product/app naming and tagline generation
- Logo direction and visual identity system definition
- Positioning and messaging for landing pages, app store, and social launch

## Outcome
Deliver a cohesive brand package with:
- clear audience and positioning,
- shortlist of validated name options,
- logo direction and visual system,
- messaging pillars and voice rules,
- channel-ready marketing starter copy.

## Required execution flow
1. Define brand foundation first (audience, problem, differentiation, promise).
2. Generate naming options with explicit rationale and risk checks.
3. Select a visual identity direction that matches product personality and market category.
4. Produce messaging pillars and reusable copy blocks.
5. Deliver a final brand kit summary with recommended next actions.

## Brand foundation checklist
- Product category and primary use case
- Target user segments and pain points
- Functional value and emotional value
- Competitive alternatives and white-space angle
- Brand personality attributes (3 to 5 traits)
- Core promise and proof points

## Naming workflow
- Generate 20+ names across patterns (descriptive, suggestive, invented, compound).
- Reduce to top 5 by memorability, pronunciation, distinctiveness, and relevance.
- Flag naming risks: ambiguity, hard spelling, over-generic terms, possible trademark/domain collisions.
- Recommend one primary name and two backups with concise rationale.

## Visual identity workflow
- Define one primary and one alternate logo direction in words.
- Specify color system (primary, secondary, neutral, semantic) with hex values.
- Specify typography pairing and fallback rules.
- Define icon/shape style and image/illustration direction.
- Define usage guardrails (minimum clear space, contrast, do/don't examples).

## Messaging workflow
- Write a one-line positioning statement.
- Write a short and long tagline option set.
- Define 3 to 5 messaging pillars with proof points.
- Define brand voice rules: tone adjectives, banned phrasing, sentence style.
- Produce starter copy for:
  - hero headline + subheadline,
  - app store short description,
  - launch post (X/LinkedIn),
  - onboarding welcome text.

## Decision guardrails
- Keep brand distinct from direct competitors in naming and tone.
- Avoid generic productivity buzzwords unless intentionally differentiated.
- Keep copy plain-language and outcome-focused.
- Keep visual direction accessible (contrast, readability, inclusive imagery).

## Delivery format for this skill
- Start with a concise brand diagnosis.
- Present naming options, then visual direction, then messaging system.
- End with a single recommended brand direction and a 30-day execution checklist.
